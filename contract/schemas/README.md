# JSON Schema контрактов (источник истины)

Файлы в этой папке — единственный источник схем для runtime и тестов:

- `m210-ProductAuthorizationRequest.tyk.json` — продуктовая авторизация
- `m095-Inbound.m096.json` — клиринг

При сборке Maven копирует их в classpath `schemas/`.

## Расширение схемы

Достаточно добавить новые атрибуты в соответствующий JSON Schema.
Если такие поля уже есть в JSON в `regression_cases`, маппер включит их в результат автоматически.
Код приложения менять не нужно (кроме бизнес-правил card / linkage / дат).

В `regression_cases` можно хранить как сырой JSON (как в m025), так и уже сформированное сообщение по схемам этой папки — параметризация одинаковая.
